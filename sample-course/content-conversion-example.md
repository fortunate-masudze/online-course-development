
# Practical Example: Converting Learning Materials into an Online Lesson

## Project Overview

**Project:** Converting Traditional Learning Materials into an Online Lesson

**Source Material:** PowerPoint presentation or PDF document

**Authoring Tools:** Articulate Rise 360 / iSpring Suite

**Delivery Platform:** Moodle LMS

**Output:** Self-paced interactive learning content

*This is an illustrative portfolio example demonstrating my content development approach.*

## 1. Reviewing the Source Material

The first stage involves reviewing the original learning material to identify:

- Main topics and subtopics.
- Learning objectives.
- Important concepts and definitions.
- Examples and illustrations.
- Existing activities and assessment questions.

## 2. Organising the Content

The original material is reorganised into a learner-friendly structure.

| Original Material | Online Learning Format |
|---|---|
| PowerPoint slides | Structured interactive lesson |
| Long paragraphs | Short, readable content sections |
| Static diagrams | Images and visual explanations |
| Examples | Interactive examples |
| Review questions | Knowledge checks |
| Summary slides | Topic summaries |

## 3. Developing the Interactive Lesson

The lesson may include:

- Introduction and learning objectives.
- Clearly organised content sections.
- Images and supporting explanations.
- Interactive knowledge checks.
- Summary and key takeaways.
- A short assessment.

## 4. Integrating the Content into Moodle

After development, the content is prepared for delivery through Moodle.

Where appropriate, the lesson is published as a SCORM package and uploaded into the relevant Moodle course.

The package is tested to check:

- Successful launching.
- Navigation between sections.
- Completion tracking.
- Assessment functionality.
- Display and usability.

## 5. Quality Assurance

The completed lesson is reviewed for:

- Accuracy of information.
- Spelling and grammar.
- Consistent formatting.
- Clear instructions.
- Functionality of interactive elements.
- Overall learner experience.

## 6. Expected Outcome

The original educational material is transformed into a structured, interactive, and self-paced online learning resource that learners can access through an LMS.
